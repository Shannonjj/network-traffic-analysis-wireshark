# Network Traffic Analysis with Wireshark (CCA 625)

Packet-analysis labs and the networking technical report from my UMGC CCA 625 (Networking Engineering) coursework.

## Wireshark Lab 1 and Lab 2 Reports
- Captured and analyzed live traffic in **Wireshark** (protocol analyzer): followed conversations, inspected packet headers, and interpreted responses
- **DNS analysis** — query/response traffic over **UDP port 53** (lookups for umuc.edu and mit.edu in the captures)
- **TCP session analysis** — connection setup, data transfer, and teardown
- **HTTP analysis** — requests and response codes, and how web traffic appears on the wire

## Project 1 — Networking in the Cloud Technical Report
- Cloud networking concepts and AWS VPC components: subnets, route tables, DHCP option sets, security groups, network ACLs, Internet Gateways, Elastic IPs, endpoints, and peering
- Accompanying **Infrastructure as Code technical report** on VPC networking
- Subnetting design exercise: carving **172.16.192.0/19** into subnets for four field offices, with hand-worked network/broadcast/usable-range calculations

## Skills demonstrated
- Wireshark packet capture and protocol analysis (DNS, TCP, HTTP)
- IPv4 subnetting and CIDR math
- Cloud networking fundamentals (VPC architecture)
